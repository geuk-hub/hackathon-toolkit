# 중단·컨텍스트 복구

## 현재 대화에서 기록 남기기

```text
다음 대화가 실제 상태에서 이어갈 수 있도록 작업 폴더에 HANDOFF.md를 작성해라.
작업 경로, 목표, 남은 요구사항 ID, 수정 파일, 현재 실행 방법, 마지막 통과/실패 명령, 미해결 오류, 주요 결정과 근거, 다음 행동 3개를 적어라.
검증하지 않은 가정과 실제 확인 결과를 분리하고 비밀을 기록하지 마라. 문서 작성 후 저장 경로를 알려줘.
```

## 새 대화에서 이어가기

```text
과제 경로 <경로>의 README, 적용되는 AGENTS.md, HANDOFF.md를 읽어라.

이미 완료한 기능을 다시 만들지 말고 남은 필수 항목부터 이어서 구현·검증해라.
남은 시간은 <분>이며 마지막 15%는 검증·제출 준비로 남겨라.
```
