# 핵심 기능 구현

```text
현재 요구사항 표와 코드를 기준으로 미완료 필수 기능을 구현해라.
먼저 가장 중요한 사용자 흐름 하나를 입력 → 처리 → 결과 표시/저장까지 연결하고 실제로 실행해라.
기존 프레임워크와 잠금 파일을 유지하고, 불필요한 전면 재작성이나 의존성 추가를 피하라.
API/함수/파일의 입력·출력 계약을 정하고 빈값, 잘못된 입력, 중복, 오류 응답을 처리해라.
데이터 저장이 요구되면 재시작 후 보존 여부를 검증해라. 요구되지 않으면 임의로 서버·DB를 늘리지 마라.
버튼은 실제 상태 변화와 연결하고, 예시 응답·가짜 성공 메시지로 기능을 대체하지 마라.
기능 하나가 끝날 때마다 가장 짧은 관련 테스트를 실행하고 다음으로 진행해라.
보고는 완료된 요구사항 ID, 수정 파일, 실행 결과, 남은 항목만 간결하게 해라.
```
