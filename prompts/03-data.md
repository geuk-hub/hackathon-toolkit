# 데이터 처리·분석 과제

데이터 과제일 때만 사용합니다. 모델 학습이 요구되지 않으면 억지로 ML 문제로 만들지 않습니다.

```text
원본 데이터는 보존하고, 먼저 파일 형식·컬럼·타입·행 수·결측·중복·키의 유일성·시간 범위를 확인해라.
단위와 타임존, 포함/제외 기준을 명시하고 join 전후 행 수를 비교해 다대다 결합으로 인한 중복 집계를 점검해라.
집계 결과의 분모와 필터 조건을 명확히 하고 작은 수동 계산 예제로 검증해라. 결측을 임의로 0으로 바꾸지 마라.
학습/예측이 요구되면 평가 지표와 제출 스키마를 먼저 확인하고 간단한 기준 모델을 만든다.
시간/그룹 구조가 있으면 그에 맞게 검증 데이터를 분리하고, 전처리 학습은 학습 데이터에만 적용해 누수를 방지해라.
랜덤 시드, 분할, 실행 명령과 실제 지표를 기록해라. 검증 데이터 결과를 시험 데이터 성능으로 표현하지 마라.
출력 ID 누락·중복, 순서, 행 수, NaN/inf, 허용 범위, 파일 인코딩을 확인해라.
수치·그래프·설명은 실제 결과에서 생성해라. 예상 성능이나 만들어낸 지표를 결과로 적지 마라.
```
