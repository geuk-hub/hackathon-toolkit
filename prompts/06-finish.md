# 마감 전 정리

```text
지금부터 새 기능과 큰 리팩터링을 중단하고 제출 가능한 상태를 만들어라.
1. 실제 과제의 제출 경로·파일명·형식·필수 내용을 다시 읽고 누락을 점검해라.
2. 핵심 동작의 재현 명령을 실행하고 실제 결과를 기록해라. 오류가 있으면 제출을 막는 결함부터 최소 수정해라.
3. README에는 실제 확인한 설치/실행/검증 명령, 입출력, 구현 범위, 미구현/한계만 적어라.
4. 문서의 기능 설명과 실제 코드·결과가 일치하는지 확인해라. 빈 템플릿, 테스트용 가짜 결과, 잘못된 경로를 찾아라.
5. 필수 원본/설정/소스/산출물이 제출 범위에 포함되는지 확인해라. 비밀이나 불필요한 대형 파일은 목록으로 보고하되 원본은 함부로 삭제하지 마라.
6. 저장 상태와 제출 파일 목록을 보여주고, 내가 수행할 수동 화면 확인과 제출 절차를 안내해라.

git push나 외부 업로드를 하지 마라. 과제 제출 버튼과 후속 서술형 시작/답변은 내가 직접 수행한다.
후속 서술형이 시작되면 AI 지원을 중단한다. 답안을 미리 만들어 제공하는 대신 구현 결정과 실제 검증 기록만 정확히 남겨라.
```
