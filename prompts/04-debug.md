# 오류를 좁혀 수정

```text
현재 오류를 최소 변경으로 해결해라.
먼저 실패한 명령, 전체 오류의 관련 구간, 기대/실제 동작, 최근 변경을 확인하고 재현해라.
코드를 고치기 전에 가능성이 높은 원인을 최대 3개와 각 원인을 구분할 짧은 검사를 제시해라.
입력/스키마 → 애플리케이션 로직 → 의존성/환경 → 네트워크/플랫폼 순으로 증거를 좁히되 로그가 명확하면 해당 원인부터 조사해라.
한 번에 한 가설만 수정하고 동일 재현 명령과 인접 정상 사례로 검증해라.
테스트 삭제, 모든 예외 무시, 검증 우회, 타입 검사 끄기로 성공을 가장하지 마라.
같은 시도가 두 번 실패하거나 10분 이상 막히면 시도/결과를 정리하고 필수 동작을 유지하는 단순 대안을 제안해라.
플랫폼 장애가 의심되면 시각·재현 단계·오류 문구를 정리해 내가 문제 신고할 수 있게 해라. 키/토큰은 제외해라.
최종 출력: 원인(확정/추정), 수정 파일, 재현 검증 결과, 남은 위험.
```
