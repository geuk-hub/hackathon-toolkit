# 제한 시간 과제 작업 지침

기존 과제 지침과 충돌하지 않는 범위에서 필요한 항목만 병합한다.

- 실제 과제 README와 제출 계약을 먼저 읽는다.
- 확인된 사실·가정·미확인 사항을 구분한다.
- 기존 스택을 유지하고 필수 흐름 하나를 먼저 끝까지 실행한다.
- 작은 변경마다 의미 있는 검증을 실행한다. 실행하지 않은 검증은 미실행으로 표시한다.
- 테스트를 삭제하거나 결과를 하드코딩해 성공을 가장하지 않는다.
- 요구사항 ID와 구현·검증 근거를 연결한다.
- 비밀을 출력하거나 외부로 전송하지 않는다. git push와 외부 AI 연결을 하지 않는다.
- Computer Use와 자동 브라우저 조작을 하지 않는다. UI 수동 검증 절차를 사용자에게 제공한다.
- 마감 직전 새 기능 대신 실행·저장·제출 형식을 확인한다.
- 후속 서술형 단계에는 AI 작업을 중단한다.
