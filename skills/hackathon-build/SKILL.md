# 작동하는 기능 구현

1. 요구사항과 기존 실행 경로를 읽고 가장 중요한 미완료 흐름을 선택하라.
2. 입력→검증→처리→출력/저장 계약을 정하라. 계약이 모호하면 되돌리기 어려운 가정만 먼저 확인하라.
3. 기존 프레임워크·의존성·잠금 파일을 우선하라. 독립 서비스나 대규모 구조를 필요 없이 추가하지 마라.
4. 한 흐름을 실제 입력으로 실행한 다음 기능을 확장하라. 가짜 응답이나 하드코딩으로 기능을 대체하지 마라.
5. 빈 입력, 잘못된 형식, 중복, 실패 경로를 처리하라. 저장이 요구된 경우 재시작 후 보존을 확인하라.
6. 데이터 집계에서는 단위·분모·결측·join 중복을 확인하라. ML 과제에서만 기준 모델과 누수 없는 검증 분할을 만들고 실제 결과를 기록하라.
7. 작은 변경마다 관련 검증을 실행하라. 주요 결정과 실패·해결 사실을 남겨라.

완료한 요구사항 ID, 변경 파일, 실행 결과, 남은 항목을 보고하라. 실행하지 못한 결과는 단정하지 마라. UI는 사용자의 직접 조작으로 검증하고 자동 브라우저 조작·외부 AI·git push·외부 전송을 하지 마라.
