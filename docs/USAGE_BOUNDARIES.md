# 사용 조건

이 저장소는 사전 준비용으로 만든 범용 자료입니다. 실제 과제 README, 응시 규정, 당일 공지가 우선합니다. 특정 과제의 완성 답안, 시험 데이터, 계정 정보, 비공개 안내문 원본은 포함하지 않습니다.

준비 시 확인한 SK하이닉스 AI 해커톤 2026 안내문(시험 필수 확인 사항 및 사전 체험·응시환경 상세 가이드)에 맞춰 다음 원칙을 적용했습니다. 안내문 원본은 재배포하지 않습니다.

- 공개 Skill·MCP·Plugin과 공개 GitHub 도구 다운로드는 허용 범위에서 활용합니다. 저장소를 시험에서 사용하려면 공개 상태여야 합니다.
- 참고·일부 알고리즘 차용과 완성 결과물 통째 대체를 구분합니다. 이 자료는 절차와 빈 템플릿만 제공합니다.
- 시험 작업물·문제·파일은 외부로 전송하거나 공유하지 않습니다. 시험 중 Git Push를 하지 않습니다.
- 제공된 Codex를 사용하며 개인 API 키, 별도 외부 AI 모델 연결을 사용하지 않습니다. 모델 선택은 당일 허용 목록을 따릅니다.
- Computer Use와 자동 화면 조작을 사용하지 않습니다. 화면 테스트는 본인이 직접 합니다.
- 후속 서술형에서는 AI와 복사·붙여넣기를 사용하지 않고 직접 답변합니다.
- 접근 제한이나 감독·보안 설정을 우회하지 않습니다.

현재 저장소를 준비·공개하는 사전 작업과 시험 중 작업물 업로드는 서로 다른 활동입니다. 시험이 시작된 뒤에는 이 저장소에 시험 내용을 추가하지 않습니다.
