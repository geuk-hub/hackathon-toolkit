# 후속 서술형 사전 연습

아래 6개는 **사전 연습용 질문**이며 실제 출제 문항이 아닙니다. 시험 후속 서술형에서는 AI 및 복사·붙여넣기를 사용하지 않고 본인이 직접 답변합니다. 이 문서는 시험 중 답안 생성용으로 사용하지 않습니다.

1. 문제를 어떤 사용자·업무 목표와 수락 기준으로 정의했는가?
2. 선택한 설계·기술과 대안은 무엇이며 왜 그 선택을 했는가?
3. AI에 어떤 단위로 작업을 맡겼고 결과를 어떻게 검토·수정했는가?
4. 가장 중요한 오류를 어떤 증거로 재현하고 해결했는가?
5. 정상·예외 동작을 어떻게 검증했고 무엇을 확인하지 못했는가?
6. 남은 한계는 무엇이며 시간이 더 있다면 무엇부터 개선할 것인가?

연습할 때는 각 질문에 '상황 → 내가 한 선택 → 실제 근거 → 한계'로 짧게 설명하세요. 수치·파일명·오류 해결 사례를 지어내지 마세요. 구현 중 WORKLOG에 남긴 사실이 본인의 설명을 돕습니다. 문항별 요구를 읽고 필요한 부분만 답하며, 위 틀을 기계적으로 반복하지 않습니다.
